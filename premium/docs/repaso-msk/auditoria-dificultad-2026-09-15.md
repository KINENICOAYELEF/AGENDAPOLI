# Auditoría de dificultad — Repaso MSK

## Hallazgo que motivó la revisión

Una prueba informal fue resuelta con 34/35 respuestas correctas. Eso no permite estimar dificultad psicométrica por estudiante, pero sí fue una señal suficiente para revisar el banco: había demasiadas preguntas de definición literal y distractores descartables sin integrar la viñeta.

## Cambios de calidad aplicados

- Cada prueba de 35 limita **Fundamentos** a un máximo de 9 preguntas. Las restantes priorizan reconocimiento contextual, interpretación, seguridad/diferencial e intervención. Fundamentos sigue siendo parte del examen: no se elimina.
- Se reemplazaron familias históricas, sin borrar sus IDs ni alterar intentos anteriores. Las nuevas versiones exigen interpretar patrón, mecanismo, función, fase o incertidumbre clínica.
- Se revisaron preguntas que podían inducir certezas indebidas: una imagen, una prueba provocadora o un hallazgo de fuerza no confirman por sí solos una estructura, lesión o plan.
- Los distractores se diseñan como alternativas clínicamente plausibles, no como absurdos, absolutos o promesas terapéuticas.

## Criterio editorial permanente

Una pregunta difícil no equivale a pedir un dato raro. Debe requerir una sola mejor decisión con datos suficientes, alternativas defendibles pero menos adecuadas y una explicación que enseñe el principio. Se evitan etiquetas anatómicas o diagnósticos cerrados a partir de un signo aislado, modelos históricos no validados como diagnóstico y promesas de regeneración o seguridad absoluta.

## Límite de esta auditoría

La dificultad real debe calcularse después con datos de intentos de internos identificados: proporción de acierto por ítem, omisiones por tiempo y capacidad de separar desempeño global alto/bajo. La prueba realizada desde una cuenta docente no se atribuye a cada interno y no debe utilizarse para calificarlos.
